# Pier acceptance record

Target edition: **16 October 2026**, revised 17 October 2026 after buyer review rounds 1 and 2. This record matches every named clause in [CONTRACT.md](CONTRACT.md). The contract describes the complete US/USD product target. Existing twelve first-release journeys retain their recorded **LOCAL PROVEN** evidence; that label applies only to their native local behavior. The added scope is not accepted merely because a journey is specified here.

Status is `done`, `partial` or `missing`, matching the contract. `done` cites implementation and exercising local tests; `partial` cites the current subset and names the remaining gap; `missing` has no implementation of the target workflow. Provider-edge test fixtures are allowed only in tests and do not establish real account, carrier, printer or warehouse acceptance. All journeys use a public UI, authenticated HTTP API, import/export door or published rer command; direct database edits cannot satisfy them.

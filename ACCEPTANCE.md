## Scope and boundaries

The local tests exercise authenticated HTTP in the real Worker with D1, empty first run, persistence, current-session role checks inside atomic admission, exact arithmetic and failed-admission atomicity. Browser tests cover the owner-facing desktop and mobile journeys. The four agent preparations—replenishment, shortage reallocation, count drift and migration—retain assumptions, evidence and exact versions; the relevant buyer, operator, warehouse person or owner must approve each exact consequence. An agent cannot self-approve, write stock, reprioritize reservations or send to suppliers.

Native CSV preview, row-group review, unchanged reimport, changed-row revision, strict parsing, duplicate opening rejection, exact `reservations.csv` allocation, safe undo and dependency-preserving correction are locally proven against the contract in [IMPORT.md](IMPORT.md). Native exit/import behavior preserves approved per-line/bin allocation and explicit zero backorders; the native snapshot does not restore complete movement, shipment, receipt-cost or transit history. Synthetic fixtures in `tests/api/security-import.test.mjs` are authored examples of Pier's native CSV contract, not external-provider exports or provider-mapping verification. Complete installation archive restore is a separate, locally proven path from business JSON export and CSV migration. This local acceptance does not establish hosted deployment, provider integration, owner-export completeness, physical counts or legal name clearance. No hosted deployment was accepted this round.

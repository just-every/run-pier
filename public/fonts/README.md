# Fonts

Every font Pier's pages use is served from this folder; no page asks another site for a font.

| Folder | Face | Used for | Licence |
| --- | --- | --- | --- |
| `pier-display/` | Pier Display | Run site headings, the "Pier" wordmark | SIL Open Font License 1.1 (`pier-display/LICENSE.txt`) |
| `inter/` | Inter (variable, 100–900) | Run site body text and drawn product cards | SIL Open Font License 1.1 (`inter/LICENSE.txt`) |
| `jetbrains-mono/` | JetBrains Mono (variable) | Commands and code on the run site | SIL Open Font License 1.1 (`jetbrains-mono/LICENSE.txt`) |
| `geist/` | Geist (variable) | App headings | SIL Open Font License 1.1 (`geist/LICENSE.txt`) |

Pier Display is a Modified Version of Anton (Copyright 2020 The Anton Project Authors, Anton has no Reserved Font Name): every outline, advance width and kerning value is narrowed to 84% horizontally with fontTools, so the heavy condensed headings match the approved homepage design, and the family is renamed. It stays under the SIL Open Font License 1.1, whose text is in `pier-display/LICENSE.txt`.

Inter and Anton are the Google Fonts builds (latin and latin-ext subsets, WOFF2). JetBrains Mono is its latin subset.
